## Getting Started

To run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/Sunil56224972/GreenBow---The-Intro.git

# 2. Navigate into the project
cd GreenBow---The-Intro

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev

# 5. Build for production
npm run build
```

Or serve the pre-built version directly:

```bash
npx http-server ./ -p 3000 -c-1
```
